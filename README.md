The last engineeringproject is:

ZURA – Smart Wearable for Pregnancy Nausea

ZURA is a wearable device concept designed to help manage pregnancy-related nausea using a non-invasive, drug-free approach.

The concept combines a wearable form factor with sensors and electronic components to monitor the user's condition and provide personalized stimulation.

Main Idea

ZURA aims to use gentle electrical micro-pulses at the P6 acupressure point as a potential way to help reduce nausea symptoms without relying on medication.

Main Technologies
ESP32 microcontroller
OLED display
Heart rate & SpO₂ monitoring
Motion sensing
Li-Po battery system
Sensors and electronic components
Wearable design
Data monitoring and alerts
Key Features
Non-invasive and drug-free concept
Wearable design
Pregnancy Mode
Health and movement monitoring
Alerts and data tracking
Potential applications beyond pregnancy-related nausea, such as motion sickness
